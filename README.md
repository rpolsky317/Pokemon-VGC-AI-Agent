# Pokemon-VGC-AI-Agent

## Dependencies

-pokeapi

-openai

## Damage Calculator Setup

This project uses the smogon open source Pokémon damage calculator service.

Clone the damage calculator repository:

git clone https://github.com/smogon/damage-calc.git damage_calc/damage-calc

Install dependencies:

cd damage_calc/damage-calc
npm install

Start the damage calculator service:

npm start
